# Ballinstadt – Konzeptstudie

Konzeptstudie zur Überprüfung von Perspektive und Darstellung. Kein Spiel und kein fertiges Produkt.

Die Studie zeigt die Auswandererhallen der Hamburg-Amerika Linie auf der Veddel (1907) als kleine Management-Simulation. Menschen durchlaufen Ankunft, Registrierung, Bad und Untersuchung, Unterbringung und Einschiffung. Ein einzelner Fall, Familie Lewin, verlangt eine Entscheidung, deren Folgen auf der Karte sichtbar werden.

**Ansichten:** Pixelgrafik isometrisch, Pixelgrafik in Draufsicht und ein historischer Lageplan im Stil der Vorlage von 1907.

**Ansehen:** https://schmettihh.github.io/ballinstadt-spike/ – oder `index.html` direkt im Browser öffnen.

Die Karte folgt dem Übersichtsplan von 1907 (Tafel Ia), vereinfacht. Personen und der Fall sind erfunden; die historischen Angaben sind nicht fachlich geprüft. Mit Hilfe von KI erstellt. Quellen: [RESEARCH.md](RESEARCH.md).
